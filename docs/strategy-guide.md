# 如何写策略 — quant-farm 提交指南

> **心智模型**：在这个系统里，"写策略" = **选一个家族（逻辑骨架已内置）+ 调一组参数（你的 alpha 假设）**。
> 你不写代码、不执行任意逻辑——验证门会替资金把关：全样本 PF>1.1、前半样本为正、成本×1.5 存活、≥10 笔交易。
> 通过后你的策略以零资金账本与生产并行运行，排行榜见真章。

## 一、四大家族

| 家族 | 何时出手 | 核心逻辑 | 适合的市场 |
|---|---|---|---|
| `long_only_breakout` | 仅 Bull | 唐奇安突破 + 放量确认 + 截面动量选最强币 | 牛市主升浪 |
| `bear_short` | 仅 Bear（BTC 空头排列≥成熟度门槛） | 顺势压破 / 拉升衰竭做空，非对称屏障 | 成熟的下跌趋势 |
| `chop_mean_reversion` | 仅 Chop | 区间边缘超卖买/超买卖回归均值 | 窄幅箱体（历史上难赚钱，验证门大概率拒） |
| `regime_router` | Bull→多头臂，Bear→空头臂 | 上面两条的组合路由 | 全天候 |

## 二、参数白名单（25 个旋钮）

### 入场与选币
| 参数 | 含义 | 建议范围 | 默认 |
|---|---|---|---|
| `top_k_momentum` | 按动量取前 N 强/弱币 | 1-3 | 3 |
| `donchian_period` | 突破通道回看小时数 | 16-30 | 20 |
| `volume_surge_mult` | 放量确认倍数（相对均量） | 1.1-1.6 | 1.30 |
| `atr_period` | 波动率 ATR 周期 | 10-20 | 14 |
| `max_bias_pct` | 乖离上限（防追极端拉伸） | 0.05-0.10 | 0.08 |
| `regime_adx_threshold` | 趋势确认 ADX 门槛 | 18-25 | 20 |
| `min_atr_percentile` | ATR 分位下限（0=关） | 0 或 70+ | 0 |

### 多头出场
| 参数 | 含义 | 建议范围 | 默认 |
|---|---|---|---|
| `initial_stop_atr_mult` | 初始止损距离 ×ATR | 1.8-2.8 | 2.2 |
| `chandelier_atr_mult` | 吊灯移动止盈距离 | 2.5-4.0 | 3.0 |
| `breakeven_r_mult` | 浮盈到 N R 后保本移损 | 1.0-2.0 | 1.5 |
| `time_stop_bars` | 时间止损小时数 | 10-24 | 16 |
| `time_stop_min_r` | 时间止损的最低浮盈 | 0.2-0.6 | 0.4 |

### 空头专属（bear_short / regime_router 的空臂）
| 参数 | 含义 | 建议范围 | 默认 |
|---|---|---|---|
| `bear_stop_atr` | 空头止损（熊市反弹猛，要比多头宽） | 2.0-3.5 | 3.0 |
| `bear_tp_atr` | 空头固定止盈（非对称：TP>SL） | 3.0-5.0 | 4.0 |
| `bear_maturity_bars` | 熊市成熟度门槛（BTC 连续空头排列小时数） | 12-48 | 24 |
| `bear_time_stop_bars` | 空头时间止损 | 8-16 | 12 |
| `bear_entry_variant` | 入场变体: breakdown / rejection / both | — | both |
| `bear_max_atr_percentile` | 危机护栏：ATR 分位超此值不开空 | 90-99 | 95 |

### 震荡回归专属（chop_mean_reversion）
| 参数 | 含义 | 默认 |
|---|---|---|
| `chop_mr_stretch_atr` | 均值拉伸入场阈值 ×ATR | 1.5 |
| `chop_mr_stop_atr` / `chop_mr_tp_atr` | 紧凑止损/均值目标价 | 1.2 / 1.0 |
| `chop_mr_range_min_pct` / `max_pct` | 有效区间宽度上下限 | 0.03 / 0.12 |
| `chop_mr_time_stop_bars` | 回归不成立就走 | 8 |

### 通用
| 参数 | 含义 | 默认 |
|---|---|---|
| `max_recent_move_bps` | 下单前波动闸门（最近10秒振幅 bps） | 30 |

> **风控参数（单笔风险/杠杆/熔断线）刻意不可覆盖**——所有账本共享生产风控纪律。

## 三、提交

**Web UI**：打开 `http://<服务器>:8787` → 填名称/作者/选家族 → 参数 JSON → 提交（约 10~30 秒验证）。

**curl**：
```bash
curl -X POST http://127.0.0.1:8787/api/strategies -H 'Content-Type: application/json' -d '{
  "name": "my_first_strategy",
  "author": "your_name",
  "mode": "bear_short",
  "params": { "bear_stop_atr": "2.5", "bear_tp_atr": "4.0" },
  "universe": ["SOLUSDT", "AVAXUSDT", "LINKUSDT", "SUIUSDT"],
  "initial_equity": "100"
}'
```

规则：名称唯一（`[a-z0-9_-]` ≤32 字符）；`universe` 必须是生产池子集；重复名先 DELETE。

## 四、验证门会怎么判你（实测过的教训）

| 你提交的 | 门会说 | 背后原理 |
|---|---|---|
| `volume_surge_mult: "1.0"`（去掉放量确认） | ❌ PF 0.68 / -16% | 无量突破=假突破磨损，414 笔白交手续费 |
| 止盈贴太近（`bear_tp_atr: "0.5"`） | ❌ 成本×1.5 翻负 | 双边 0.1% 成本吃掉全部回归利润 |
| 参数只在近期行情有效 | ❌ 前半样本净利 ≤0 | Walk-forward 防过拟合：两个时段都得为正 |
| 交易太少（<10 笔） | ❌ 样本不足 | PF 没有统计意义 |

## 五、从提交到"转正"

```
提交 → 验证门(30s) → 零资金账本并行 → 攒 ≥20 笔闭环 → 账本 PF>1.1 且 平均R>0
→ 排行榜标"达标" → 人工评估是否给真资金
```

你的账本亏了不赔一分钱；跑赢了就是转正谈判的全部依据。**排行榜只认数据。**

## 六、调参心法（来自本项目三次失败研究的浓缩）

1. **成本是头号敌人**：每笔往返 ~0.2%（费+滑）。任何"高频-小目标"参数组合先算成本账。
2. **过滤器宁多勿少**：放量、乖离、成熟度门都是防磨损的——去掉它们省下的心算，验证门会加倍还回来。
3. **止损要给波动留空间**：多头 2.2 ATR / 空头 3.0 ATR 不是拍脑袋——太紧会被正常波动扫出局。
4. **别在一个时段上优化**：前半样本门就是为此存在的。你调到全样本漂亮但前半拉胯，照样拒。
5. **失败的家族也有价值**：`chop_mean_reversion` 历史上 4 组参数全负——除非你有新想法，提交它基本是给门送人头（但门会礼貌地告诉你为什么）。
