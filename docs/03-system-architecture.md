# 03 - 系统架构与实盘落地路线图（Rust 金融级高可靠架构）

在数字货币实盘交易中，**半夜极端插针行情下的系统存活率**决定了一切。为了实现
“零空指针崩溃、零浮点数精度拒单、零 GC 停顿、回测与实盘 100% 同源”，本系统采用
**纯 Rust 单体模块化架构**，编译为单一静态二进制文件，可在 Mac 本地或任何海外轻量
云服务器上以低于 20 MB 的内存占用 7×24 小时稳定运行。

## 一、 为什么选择 Rust 而不是 Python 或 Go？

| 核心痛点 | Python 的隐患 | Go 的短板 | Rust 的降维打击优势 |
| --- | --- | --- | --- |
| 下单价格/数量精度 | `float` 精度丢失导致交易所拒单 | `decimal` 库无运算符重载，公式可读性差 | `rust_decimal` 128 位定点数 + 原生运算符，100% 杜绝精度拒单 |
| 极端行情异常处理 | 动态类型，运行时才爆 `TypeError` 崩溃 | 容易漏写 `err != nil` 或误用结构体零值 | `Result`/`Option` 与穷尽式 `match`，漏处理分支直接无法通过编译 |
| 订单状态机安全 | 状态流转靠人工约定，易出现僵尸单 | 缺乏代数数据类型（Enum 弱） | 强类型枚举状态机，从编译器层面杜绝“重复平仓/反向开仓” |
| 性能与未来扩展 | 慢，无法做毫秒级公告抢跑与高频盘口 | 有 GC 停顿 | 零 GC 纳秒级响应，未来可无缝升级至毫秒级公告抢跑与高频套利 |

## 四、 核心 Rust 技术栈（Crates 选型）

| 领域 | 核心 Crate | 作用说明 |
| --- | --- | --- |
| 异步运行时 | `tokio` | 工业级异步多线程运行时，管理 WebSocket 长连接与并发定时任务 |
| 金融高精度计算 | `rust_decimal` | 128 位十进制高精度定点数，彻底消灭浮点数精度误差与拒单 |
| 网络与加密签名 | `reqwest` + `tokio-tungstenite` + `hmac` | 低延迟 REST 下单、WebSocket 实时流、交易所 HMAC-SHA256 签名 |
| 序列化与配置 | `serde` + `serde_json` + `toml` | 零开销强类型 JSON/TOML 解析，字段缺失或类型错误即时拦截 |
| 数据持久化 | `sqlx` / `rusqlite` | 本地存储历史 K 线、资金费率及实盘每一笔订单的完整审计日志 |
| 命令行与日志 | `clap` + `tracing` | 结构化全链路日志追踪，精确记录每次信号计算与下单耗时 |

## 五、 回测“防作弊”验证标准（上线实盘前必过门槛）

任何策略参数在投入 200 USDT 实盘前，必须通过以下严苛回测检验：

1. **真实成本扣减**：每笔开平仓强制扣除 **0.05% Taker 手续费 + 0.05% 滑点**（即一买一卖直接先扣 0.20%），并按历史真实资金费率每 8 小时结算一次。
1. **严格时间对齐**：信号在 `T` 时刻 K 线收盘后计算，成交价必须使用 `T+1` 根 K 线的开盘价 `(Open)`，严禁使用当根 K 线盘中价格撮合。
1. **交易所精度模拟**：回测中每一笔下单都强制执行 `step_size`（最小数量步长）和 `min_notional`（最小下单金额 >= 10 USDT）截断，模拟 200 USDT 真实资金限制。
1. **实盘准入指标**：
   - 扣除所有成本后，年化夏普比率（Sharpe Ratio）**> 1.5**。
   - 历史最大回撤（Max Drawdown）**< 18%**。
   - 盈亏比（Profit Factor）**> 1.4**，且不依赖单一极端幸存者币种。

## 六、 四阶段落地执行计划（Roadmap）

1. **阶段一：Rust 核心底座与历史回测验证（第 1～2 天）**
   - 初始化 Rust 工程，实现核心指标库、以损定仓风控器、历史 K 线下载器（`coin-ai download`）与防作弊回测引擎（`coin-ai backtest`）。
   - 用过去 1 年真实市场数据跑出 200 USDT 起步的净值曲线、最大回撤与每笔交易明细。
1. **阶段二：交易所实盘网关与硬止损同步（第 3～4 天）**
   - 实现合约下单、精度自动对齐、服务端 `STOP_MARKET` 硬止损单挂载与断网重连自愈。
   - 接入飞书 / Telegram 实时告警推送。
1. **阶段三：Dry-Run 模拟盘与 20 USDT 最小单点火测试（第 5～7 天）**
   - 运行 `coin-ai dry-run` 48 小时验证实时信号，再用 20 USDT 跑通真实开平仓与止损单触发闭环。
1. **阶段四：200 USDT 正式实盘运行与 AI 风险否决接入（第 8 天起）**
   - 正式注入 200 USDT 全自动运行，接入 LLM 公告风险否决器与极端负费率狙击模块。
