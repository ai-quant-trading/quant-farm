# 02 - 200 USDT 风控与仓位管理规范

在数字货币量化中，**策略决定你能赚多少，风控决定你能活多久**。针对 200 USDT
测试本金，我们制定以下不可逾越的铁律（写死在代码底层拦截器中，任何策略模块无权绕过）。

## 一、 以损定仓模型（Risk-Based Position Sizing）

严禁按“固定金额”或“固定杠杆倍数”拍脑袋开仓。所有仓位大小必须由**止损距离**倒推计算，
确保无论交易的是波动小的 BTC 还是波动极大的山寨币，触发止损时亏掉的钱完全相同。

### 1. 核心计算公式

设账户当前总权益为 $E$（初始 $E = 200\text{ USDT}$），单笔交易最大允许风险比例为
$r = 1.5\%$（即单笔最多亏损 $3\text{ USDT}$）：

$$\text{单笔最大允许亏损金额 } Risk_{USD} = E \times r = 200 \times 1.5\% = 3.0\text{ USDT}$$

设某币种当前开仓价格为 $P_{entry}$，根据 $2.2 \times ATR(14)$ 计算出的止损价格为
$P_{stop}$，则止损幅度（含预估双边手续费与滑点 $c = 0.2\%$）为：

$$d = \frac{|P_{entry} - P_{stop}|}{P_{entry}} + c$$

则该笔交易应开立的**合约名义价值（Notional Value）**为：

$$\text{Notional} = \frac{Risk_{USD}}{d}$$

### 2. 算例演示

假设某币种当前价格 $P_{entry} = 10.0\text{ USDT}$，根据 ATR 算出止损价为
$P_{stop} = 9.62\text{ USDT}$（止损距离 $3.8\%$，加上 $0.2\%$ 交易磨损，总风险距离
$d = 4.0\%$）：

$$\text{应开仓名义价值 Notional} = \frac{3.0\text{ USDT}}{4.0\%} = 75\text{ USDT}$$

- 此时开仓 $75\text{ USDT}$ 的合约（仅相当于 $200\text{ USDT}$ 本金的 $0.375$ 倍有效杠杆）。
- 一旦行情看错触发止损，账户精准亏损 $75 \times 4.0\% = 3.0\text{ USDT}$，剩余本金
  $197\text{ USDT}$，完全不伤元气。

## 二、 仓位上限与杠杆硬约束

为了防止多个持仓同时同向亏损，底层风控网关（Risk Gateway）执行以下硬上限：

| 风控指标 | 硬性阈值 | 200 USDT 对应数值 | 说明 |
| --- | --- | --- | --- |
| 单笔最大风险 ($r$) | <= 1.5% | 3.0 USDT | 单次止损允许的最大本金折损 |
| 单币种最大名义仓位 | <= 60% 总权益 | 120 USDT | 防止止损过窄算出的名义仓位过大 |
| 单币种最小名义仓位 | >= 15 USDT | 15 USDT | 高于交易所 5～10 USDT 最小下单门槛 |
| 最大同时持仓币种数 | <= 3 个 | 最多 3 个仓位 | 分散风险同时避免过度碎片化 |
| 账户总名义持仓上限 | <= 200% 总权益 | 400 USDT | 账户整体有效杠杆永远不超过 2.0x |
| 同方向最大风险敞口 | <= 4.5% | 9.0 USDT | 即使 3 个仓位全部同时打止损，最多亏 4.5% |

## 三、 三级账户熔断机制（Circuit Breakers）

当市场出现罕见黑天鹅或策略进入不适应期时，系统自动触发降级或停机保护：

### 1. 一级熔断（日内冷却）

- **触发条件**：单日（UTC 00:00 起算）已实现亏损 + 浮动亏损达到总权益的 **5%（10 USDT）**。
- **执行动作**：拒绝当日所有新开仓信号，进入 24 小时冷却期，并向 Telegram / 飞书发送黄色预警。

### 2. 二级熔断（降仓防御）

- **触发条件**：连续 5 笔交易止损，或滚动 7 天最大回撤达到 **10%（20 USDT，账户剩 180 USDT）**。
- **执行动作**：自动将单笔风险系数 $r$ 从 $1.5\%$ 减半至 **$0.75\%$（单笔最多亏 1.35 USDT）**，只有当净值重新收回 190 USDT 以上才恢复正常仓位。

### 3. 三级熔断（硬停机保護）

- **触发条件**：账户总权益跌破 **160 USDT（累计回撤达到 20%）**，或监测到交易所 API 连续报错、签名异常。
- **执行动作**：
  1. 立即撤销所有挂单并市价平掉所有持仓。
  1. 锁死交易守护进程（`TRADING_ENABLED = False`）。
  1. 发送红色最高级别告警，必须由人工复盘日志并手动解除锁定后方可重启。

## 四、 工程级防爆仓与执行安全细节

1. **逐仓模式（Isolated Margin）优先**：每个币种使用独立逐仓保证金（配置 3x～5x 标称杠杆），即便单个小币种发生史诗级瞬间归零/插针，最大损失也严格限制在该仓位分配的几十 U 保证金内，绝不牵连账户其余资金。
1. **交易所端服务端止损（Server-Side Stop Loss）**：严禁只在本地 Python 内存里记止损价。开仓成交后 1 秒内必须在交易所挂好 `STOP_MARKET`（触发市价止损单，带 `reduceOnly=True`）。如果止损单挂单失败，系统将在 3 秒内自动市价平掉刚刚开出的仓位（裸奔仓位零容忍）。
1. **防重复下单（Idempotency）**：每笔订单生成唯一 `clientOrderId`，遇到网络超时先查单（`fetch_order`），绝不盲目重发市价单。
